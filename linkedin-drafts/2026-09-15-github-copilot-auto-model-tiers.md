## Newsletter Title

GitHub Copilot Auto Gets Cost And Quality Tiers

## Intro

GitHub Copilot auto model selection now has efficiency, balance, and intelligence tiers, giving teams a practical way to steer cost, latency, and quality without picking a model for every prompt.

## Takeaways

- Copilot auto model selection already routed prompts based on task complexity, model availability, and system health. The new part is an explicit preference layer.
- Most teams do not need more model names in a dropdown. They need a default that makes everyday work cheap and quick, while still leaving room for deeper reasoning when the task deserves it.
- GitHub's docs describe auto model selection as two systems working together.
- The next useful step would be better reporting.
