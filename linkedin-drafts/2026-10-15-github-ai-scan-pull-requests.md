## Newsletter Title

GitHub AI Scan Expands Pull Request Security Coverage, but It Won't Block Merges

## Intro

GitHub AI Scan now checks pull request changes in PHP, Bash, Terraform, Dockerfiles, and other gaps in CodeQL coverage, with advisory findings and separate AI-credit billing.

## Takeaways

- AI Scan now runs automatically on qualifying pull requests when code scanning and the repository's effective AI Scan setting are enabled.
- Static analysis coverage often stops at a language boundary.
- The next useful step would be a promotion path from a confirmed AI finding to a deterministic, enforceable rule.
