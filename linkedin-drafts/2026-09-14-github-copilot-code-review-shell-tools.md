GitHub Copilot Code Review Gets Closer to Real CI

## Intro

GitHub Copilot code review now uses broader shell tools and an ensemble of agents in Lite reviews, which makes AI review more useful but also worth treating like CI automation.

## Takeaways

- On the review workflow side, Copilot code review can now resolve its own comments after a later commit addresses them.
- The important part is not that Copilot can leave more comments.
