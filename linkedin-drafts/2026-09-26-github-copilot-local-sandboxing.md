## Newsletter Title

Copilot Local Sandboxing Makes Agent Permissions Concrete

## Intro

GitHub Copilot app local sandboxing turns agent permissions into per-project policy, which is the right default shape for developer machines.

## Takeaways

- Local sandboxing now applies to local repository and working tree sessions in the GitHub Copilot app.
- Agent risk is usually described in abstract terms: prompt injection, unintended commands, overbroad credentials, or accidental writes.
- The project settings describe the policy the app requests when a sandboxed session starts.
- The preview is interesting because it makes local agent governance less hand-wavy.
