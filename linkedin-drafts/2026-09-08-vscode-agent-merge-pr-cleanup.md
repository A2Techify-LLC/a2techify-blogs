## Newsletter Title

VS Code Agent Merge Turns PR Cleanup Into An Agent Loop

## Intro

VS Code 1.136 adds Agent Merge in preview, giving coding agents a narrower loop for review feedback, failing checks, stale branches, and merge conflicts.

## Takeaways

- VS Code 1.136 was released on September 2, 2026.
- Small teams do not need an agent that only creates more review work. They need an agent that can close loops without hiding important decisions.
- The feature starts from an active agent session in the Agents window.
- The useful next layer is traceability.
