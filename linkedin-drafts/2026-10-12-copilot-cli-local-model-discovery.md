## Newsletter Title

Copilot CLI Local Model Discovery Makes BYOK Less Awkward

## Intro

GitHub Copilot CLI can now discover supported Ollama models from the model picker, but local model routing still needs clear privacy and capability checks.

## Takeaways

- Copilot CLI already supports bring-your-own-key and custom model providers, including OpenAI-compatible endpoints such as Ollama, vLLM, Foundry Local, and other local or remote services.
- Local model support is most useful when it becomes a normal part of the developer workflow instead of a separate experiment.
- GitHub's docs describe three provider types for Copilot CLI: openai, azure, and anthropic.
- GitHub also teased intelligent routing with local models.
