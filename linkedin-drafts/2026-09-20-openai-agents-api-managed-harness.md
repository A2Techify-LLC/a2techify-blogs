## Newsletter Title

OpenAI's Agents API Turns the Harness Into a Product

## Intro

OpenAI's public beta Agents API exposes the managed Codex harness, including sessions, sandboxes, compaction, tool search, and subagents.

## Takeaways

- The Agents API lets developers create hosted agent sessions with a model, instructions, tools, and an environment.
- Most agent prototypes hide a lot of harness work in glue code. The first demo may only need a model call, a tool registry, and a while loop. Production work quickly asks harder questions:
- The main concepts are agent, environment, session, and events.
- The open question is how portable agent applications become when the harness is managed.
